# Bright Minds Explorers World

A K–5 learning world in 3D and VR from **Bright Minds Explorers Academy** (PenGame Publishing). It grows out of *Nia's VR World: The Magic Number Garden* and adds five new places to explore.

**Play:** https://mrimagemakers.github.io/brightmindsacademy/ (after GitHub Pages is turned on)

## What's inside

| Place | Friends | Games |
|---|---|---|
| 🌸 The Number Garden | Nia, Freddy, Addie, Carlo, Subby, Milly, Skippy, Gwenda, the Number Eight Butterfly | 17 math games from the book |
| 🏫 Explorers Academy | — | Math Masters (K–5), grade picker, portals, the 5 Reading Crystals |
| 🦁 Leo's Word Safari | Leo the Lion | Word Safari (phonics → vocabulary by grade) |
| 🦉 Reading River | Oliver Owl, Toby Tortoise | Story Time (read-along comprehension), Spelling Stroll |
| 🤖 Explorers STEM Lab | Katie Kangaroo, Gizmo the Robot | Code Gizmo (arrows, sequences, loops), Logic Lab |
| 🔭 Sky Observatory | Sloth Sage | Science Quest, Star Gazer |

- **Grade levels K–5.** Pick a grade on the title screen or the 🎒 button and every new game adjusts.
- **Reading Crystals.** Score 3+ stars on each zone's main game to earn its crystal. Five crystals chase the Silence Shadow off the Academy tower and unlock the Explorers Passport.
- **Grown-ups view** (👪 button): rounds played, first-try accuracy by subject, minutes played, and a suggested next game.
- Desktop (WASD + mouse), phone (touch joystick), and VR headsets (Quest browser: tap **Enter VR**).

## Files

- `index.html` is the whole site in one file.
- `source/nia-world-base.html` is the Number Garden build it starts from; `source/bright-minds-expansion.js` holds the new zones, characters, and games; `source/build.py` applies them to make `index.html`.
